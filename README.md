# Сложно сосредоточиться

Проектная работа курса Яндекс Практикума.

## Описание

Адаптивная страница о концентрации внимания с тёмной и светлой темами.

В проекте реализованы:

- семантическая HTML-разметка;
- адаптивная сетка для мобильного, планшетного и десктопного экранов;
- переключение цветовых схем;
- декоративные элементы шапки и подвала;
- галерея изображений с ленивой загрузкой.

## Технологии

- HTML
- CSS
- JavaScript
